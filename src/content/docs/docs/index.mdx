OT Fabric is an open-source ecosystem for industrial connectivity and interoperability: protocol **libraries**, field-ready **command-line tools** and **interoperability suites** for twelve OT communication protocols, libraries and tools for two standard information models, the same toolkit for the Sparkplug B messaging profile, plus network visibility, desktop apps, captures and simulation. These docs explain how each protocol, model and profile works and how to use every project.
